🤖 Automata Theory

NFA → DFA Conversion Engine

A deep-logic Java tool that converts Regular Expressions into Minimized Deterministic Finite Automata — with automated Graphviz state machine visualizations. Built from scratch using formal language theory.

  • Parses regex into NFA using Thompson's construction
  • Converts NFA → DFA using subset construction algorithm
  • Minimizes DFA using Hopcroft's algorithm
  • Generates Graphviz DOT files for visual state diagrams
Java Automata Theory Graphviz Formal Languages Graph Algorithms

// concepts used
⚙️
Thompson's Construction Converts a Regular Expression into an NFA using a recursive algorithm with epsilon transitions.
🔄
Subset Construction Converts NFA to DFA by computing epsilon-closures and tracking sets of NFA states as DFA states.
✂️
DFA Minimization Reduces the number of states by merging equivalent states using partition refinement.
📊
Graphviz Visualization Outputs DOT language files to render clean, readable state machine diagrams automatically.
