🤖 Automata Theory

NFA → DFA Conversion Engine

A deep-logic Java tool that converts Regular Expressions into Minimized Deterministic Finite Automata — with automated Graphviz state machine visualizations. Built from scratch using formal language theory.

  • Parses regex into NFA using Thompson's construction
  • Converts NFA → DFA via subset construction algorithm
  • Minimizes DFA using Hopcroft's algorithm
  • Generates Graphviz DOT files for visual state diagrams
Java Automata Theory Graphviz Formal Languages Graph Algorithms
View on GitHub ↗
// concepts used
⚙️
Thompson's Construction Converts a regex into an NFA using a recursive algorithm with epsilon transitions.
🔄
Subset Construction Converts NFA to DFA by computing epsilon-closures and tracking sets of NFA states as DFA states.
✂️
DFA Minimization Reduces states by merging equivalents using partition refinement (Hopcroft's).
📊
Graphviz Visualization Outputs DOT language files to render clean, readable state machine diagrams automatically.

🧩 AI / Search Algorithms

Maze Agent

A Flask web app where a neural network looks at a maze, predicts how hard it is, and an agent then chooses the search algorithm — BFS or A* — it expects to work best. Everything is visualized in the browser.

  • Random maze generation with a recursive backtracker
  • MLP difficulty classifier (EASY / MEDIUM / HARD) trained on synthetic mazes
  • Agent explains why it picked BFS or A*
  • Compare explored nodes and path length for both algorithms
Python Flask scikit-learn BFS A* JavaScript
